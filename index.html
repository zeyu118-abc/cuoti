JSON 录入

最快方式：把试卷照片交给 AI 转成 JSON。复制提示词 → 粘贴到豆包 / DeepSeek 对话框 → 上传题目照片。

上传 JSON 文件批量录入题目，可以是别人的备份文件，也可以是自己按规则生成的文件。导入后一律当作你的全新题目（已清空复习进度）。

格式说明

  • 整体是一个 JSON 数组 [ ... ]，每道题是一个对象；粘贴时带 ```json 代码块或前后解释文字也能自动识别
  • type：single=单选、multiple=多选、judge=判断（写成「单选/多选/判断」也能识别）
  • question_text：题干文字（写成 question / stem / title 也能识别）
  • options：选项数组，每个选项用对象 { "label":"A", "text":"内容" }；也可直接写成字符串数组 ["选项A", "选项B", ...]（会自动识别 A./B./1. 前缀）；选项可加 image 放图片
  • answer：正确选项字母数组，单选如 ["D"]，多选如 ["A","C"]（也可写成 "AC" 或 "A,C"），判断 ["A"]=对、["B"]=错
  • note：备注（可选）
  • question_image：题干图片（可选，填图片网址或 base64）
  • subject：错题来源科目（可选）：电路 / 电机 / 电分 / 继保 / 高压 / 设备 / 电力电子 / 行测，不填为未分类

纯文本题目示例

[
  {
    "type": "single",
    "question_text": "下列关于潮流计算的计算机算法中，错误的是",
    "options": [
      { "label": "A", "text": "牛顿-拉夫逊法按平方关系收敛，效果最好" },
      { "label": "B", "text": "PQ分解法按线性关系收敛，速度慢于牛顿法" },
      { "label": "C", "text": "PQ分解法主要用于输电系统潮流计算" },
      { "label": "D", "text": "PQ分解法计算速度最快，高斯-赛德尔最慢" }
    ],
    "answer": ["D"],
    "note": "潮流计算",
    "subject": "电分"
  },
  {
    "type": "judge",
    "question_text": "电力系统的频率是衡量电能质量的重要指标之一",
    "options": [
      { "label": "A", "text": "正确" },
      { "label": "B", "text": "错误" }
    ],
    "answer": ["A"]
  }
]

      { "label": "A", "text": "10Ω" },

    ],
    "answer": ["B"]
  }
]

# 国家电网错题本（手机版）

纯网页错题本，**免费、无需服务器**。手机浏览器打开网址即可使用，数据存在手机本地。

## 功能

- **录入错题**：拍照/上传题目图片，文字用手机自带识别后粘贴 → 核对修正 → 选答案保存
- **题目和选项都能配图**：题干、每个选项都可以单独上传图片，图文一起展示
- **三种题型**：单选（4 选项）、多选（4 选项）、判断（A=正确 / B=错误）
- **遗忘曲线复习**：次日复习，之后按 1 → 3 → 7 → 15 → 30 天间隔，做错自动重来
- **错题管理**：列表查看、详情、删除
- **导出 / 导入备份**

## 部署到手机可访问（Cloudflare Pages，免费）

只需上传一次，之后手机随时打开网址就能用。

### 第一步：注册 Cloudflare

1. 电脑浏览器打开 https://dash.cloudflare.com/sign-up
2. 用邮箱注册并登录（免费）。

### 第二步：上传网站文件

1. 登录后，左侧菜单找到 **Workers 和 Pages**（或直接打开 https://dash.cloudflare.com/pages）。
2. 点 **Create（创建）** → 选 **Pages** → 选 **Upload assets（上传资源）**。
3. 给项目起个名字（如 `cuoti`）。
4. 把你电脑上的 **`cuoti-web` 整个文件夹**（包含 `index.html`、`_worker.js`、`logo.png`、`css`、`js`）拖拽到上传区域。
5. 点 **Deploy（部署）**。

### 第三步：手机访问

部署完成后，会得到一个网址，形如：

```
https://你的项目名.pages.dev
```

**在手机浏览器输入这个网址**，就能使用了。把这个网址收藏或发到微信，以后随时打开。

## 重要提示（必看）

1. **数据存在手机浏览器本地**，不上传任何服务器。所以：
   - 清除浏览器数据 / 卸载浏览器，数据会丢失 → **请定期用「导出备份」保存一份**。
   - 换浏览器或换手机，数据不自动同步 → 用「导出备份」后在新设备「导入备份」。
2. **电脑和手机数据不互通**：各自浏览器各自存。你主要用手机，就在手机上录入和复习。
3. **文字识别用手机自带功能**：本网站不做自动识别。你可以用手机自带的「拍照取字 / 提取文字」功能把题目文字提取出来，再粘贴到本网站对应的框里（题干、每个选项）。
4. 公式、图形、表格等无法用文字表达的内容，**直接上传图片**即可（题干和每个选项都能单独配图）。

## 私人 AI 解析（可选，仅自己使用）

网页内置的「AI 解析」默认不显示，只有输入过私人口令的设备才会出现。

1. 在 Cloudflare Pages 项目里进入 **设置 → 变量和机密**，添加：
   - `DEEPSEEK_API_KEY`：机密，DeepSeek 开放平台创建的 API Key
   - `AI_TOKEN`：机密，自己设置的长口令（20 位以上，不要用生日/手机号）
   - `DEEPSEEK_MODEL`：文本，可填 `deepseek-flash`
2. 重新上传包含 `_worker.js` 的整个文件夹。
3. 自己手机打开 `https://你的网址/#ai-unlock`，输入一次口令。日常请打开**不带 `#ai-unlock` 的普通网址**并重新收藏。
4. 提交答案后会出现「AI 解析」；解析中的 A/B/C/D 对应当前打乱后的选项顺序。题干和选项上传的图片会一起发给 AI（deepseek-flash 支持识图），纯文字题不受影响。别人的设备没有口令，看不到按钮，也无法调用接口。
5. 想在本机关闭：打开 `https://你的网址/#ai-lock`；想换口令：先 `#ai-lock`，再 `#ai-unlock`。

AI 答案仅供参考，请以题目给定答案为准；每次解析会产生少量 DeepSeek 费用。带图片的题会先把压缩后的图片一起上传，解析稍慢、消耗的 token 略多；纯文字题不受影响。

## 在电脑上本地预览（可选）

如果你只想先在电脑上看看，双击 `index.html` 用浏览器打开即可（推荐用 Chrome/Edge）。本地预览时 AI 功能不可用，需要部署到 Cloudflare Pages。
